Projects

Jarvis

Voice agent · Brokai Labs · a team project I started

A voice assistant that remembers context and gets work done across Slack, Linear, Gmail, Calendar and Notion, so you can ask once instead of switching between five apps.

What I did

I started Jarvis and wrote most of the first voice agent on LiveKit, then brought in collaborators and led the team as it grew. I evaluated it with 30–40 test cases per round, scoring task completion, tool routing and answer relevance.

How it works

  1. You speak; LiveKit streams the voice session
  2. Jarvis recalls what it knows about you and the task
  3. It picks the right workplace tool
  4. It takes the action or answers back by voice
  5. Every run is traced and scored

Proof

Built on LiveKit with persistent memory, tool handlers for Slack, Linear, Gmail, Calendar and Notion, and tracing on every session. Each evaluation round used 30–40 cases.

About the demo

  • The demo here is a small rule-based Slack-to-Linear example, so you can see the flow without connecting real accounts.
  • The full system was built with a team, and its code is private.

Hapi

Prototype · my own project

One API that lets an AI agent take actions in Gmail, Sheets, Slack and PostgreSQL, instead of a separate integration for every app.

What I did

I designed and built Hapi, with my team supporting the work. It puts four connector families and 28 actions behind a single execution endpoint.

How it works

  1. The agent sends one authenticated request
  2. Hapi finds the action in its registry
  3. The right connector runs it with stored, encrypted credentials
  4. The reply is trimmed to what the agent needs, and the run is logged

Proof

FastAPI backend with OAuth and API-key sign-in, encrypted credentials, database migrations, configurable response fields, execution logs and a React management screen.

About the demo

  • Hapi is a prototype, not a product in production.
  • This site does not connect to any real account.

What I did

I took it from the first customer conversation to launch: scoping the calls, building the agent on Retell and rolling it out.

How it works

  1. A client calls the salon
  2. The agent understands the request and collects the details
  3. It checks availability and runs the booking tools
  4. It confirms the booking or change on the call
