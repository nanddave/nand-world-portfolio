                  How this was built

                  • Static web application. Vite builds a JavaScript and three.js site with lazy-loaded city and mission modules. It is hosted on Vercel; a single-file build also provides a readable offline fallback.
                  • Procedural three.js. Buildings, cars and kites are built from code: boxes, lathes and extrusions. No downloaded models.
                  • A real Earth. Coastlines come from Natural Earth's public-domain land data, packed into a 32 KB bit mask. Mountains, biomes and clouds are generated.
                  • Demos run in your browser. The missions do their work on your device; "Show your work" lists each step they actually ran. Anything scripted says so.
                  • Co-pilot search. By default it ranks the stories locally with BM25 and a small synonym list. An optional configured endpoint can answer remotely; the standalone build stays local.
                  • Drive mode and real streets. The yellow car is arcade physics against box colliders derived from the scene; Bangalore's streets and buildings are OpenStreetMap data baked offline into a small JSON file (© OpenStreetMap contributors), with approximate building heights.
                  • Local time and optional weather. Time comes from your browser's clock and the city's time zone. The designed scene is the default; where available, Open-Meteo weather can be selected. The standalone file makes no weather request.
                  • Voice is the browser's own. The mic button and the spoken answers use your browser's built-in speech features (speech recognition and speech synthesis). This site never records or stores audio; where your browser sends speech for recognition is up to the browser.
                  • Your own city. In the hosted version, a city name is sent to a geocoder and OpenStreetMap's Overpass to draw streets; a designed street is used when those requests fail. The standalone build uses the designed street without these requests.
                  • Runtime and code access. The site uses no paid APIs or assets in this build. Sound is synthesised with WebAudio. Visits are counted with Vercel Web Analytics, which uses no cookies. The code for this portfolio is open on GitHub; the client and team projects it describes stay private.
